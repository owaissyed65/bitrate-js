Encode & package frames packageFrames()

Real H.264 encoded in-browser from canvas frames, then packaged and played back. This is the end-to-end proof — no source file involved.

Audio muxed second track

A source with sound must come out with sound. Audio frames are copied untouched and muxed as a second track in the same segments, with the two timelines kept in step.

Transcode to an ABR ladder mode: transcode

Decode once, re-encode into several bitrates, emit a master playlist. Needs a real H.264 MP4 — the generated sample has synthetic frame payloads a decoder will reject, so pick a genuine video here.

Queue: many files, failures survived HlsQueue

Three jobs are queued — and the middle one is deliberately corrupt. The batch must record it and keep going, which is what drain() reports.

Resume after an interruption IndexedDB

Starts a job, kills it partway as if the tab closed, then resumes from the checkpoint — and checks the stitched result matches an uninterrupted run.

Upload adapters upload-to-anywhere

Every output file reaches your uploader in the same shape, whatever the backend. This mock records what a real S3 / Supabase / Appwrite adapter would receive.
